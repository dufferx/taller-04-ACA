    Empezando con QuesadillaAPI#

    ¡Bienvenido a QuesadillaAPI! Esta guía te ayudará a comenzar con nuestra deliciosa API en solo unos minutos.

    Prerequisitos#

    Antes de comenzar, asegúrate de tener:

    • Conocimiento básico de APIs REST
    • Un editor de código (VS Code, PyCharm, etc.)
    • Python 3.8+ o Node.js 14+ instalado
    • Apetito por las quesadillas 🌮

    Instalación#

    ```python

    Instalar el cliente de QuesadillaAPI#

    pip install quesadilla-api-client

    Importar e inicializar#

    from quesadilla_api import QuesadillaClient

    client = QuesadillaClient(api_key="tu_clave_api_aqui") ```

    ```javascript // Instalar via npm npm install quesadilla-api-sdk

    // Importar e inicializar const QuesadillaAPI = require('quesadilla-api-sdk');

    const client = new QuesadillaAPI({ apiKey: 'tu_clave_api_aqui', baseURL: 'https://api.quesadilla.com/v1' }); ```

    Ejemplo de Inicio Rápido#

    Aquí tienes un ejemplo simple para crear y rastrear un pedido de quesadilla:

    # Crear un nuevo pedido de quesadilla
order = client.create_order({
    'type': 'chicken',
    'size': 'large',
    'toppings': ['cheese', 'guacamole', 'sour_cream'],
    'spice_level': 'medium',
    'customer_name': 'Carlos Mendoza'
})

print(f"¡Pedido creado! ID: {order.id}")
print(f"Entrega estimada: {order.estimated_delivery}")

    Consejo Pro

    Siempre verifica que tu clave API sea válida antes de hacer peticiones. Puedes probarla con un simple endpoint GET /health.

    Configuración del Entorno#

    Crea un archivo .env en la raíz de tu proyecto:

    QUESADILLA_API_KEY=tu_clave_secreta_aqui
QUESADILLA_BASE_URL=https://api.quesadilla.com/v1
QUESADILLA_TIMEOUT=30

    Formato de Respuesta de la API#

    Todas las respuestas de la API siguen esta estructura:

    Campo Tipo Descripción
    success boolean Si la petición fue exitosa
    data object/array Los datos reales de respuesta
    message string Mensaje legible para humanos
    timestamp string Timestamp ISO de la respuesta

    Ejemplo de respuesta:

    {
    "success": true,
    "data": {
        "id": "quesadilla_123",
        "type": "chicken",
        "status": "preparing",
        "estimated_time": "8 minutes"
    },
    "message": "Pedido creado exitosamente",
    "timestamp": "2024-01-15T10:30:00Z"
}

    Límite de Velocidad

    Nuestra API tiene límites de velocidad de 100 peticiones por minuto. Si excedes esto, recibirás un código de estado 429.
