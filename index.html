    Documentación de QuesadillaAPI#

    Bienvenido a QuesadillaAPI - la API REST definitiva para gestionar quesadillas en tu restaurante o aplicación de delivery de comida.

    Resumen#

    QuesadillaAPI proporciona una interfaz simple pero poderosa para gestionar pedidos de quesadillas, ingredientes y seguimiento de entregas. Construida con Python FastAPI, ofrece alto rendimiento y documentación automática de la API.

    Endpoints de la API#

    ```python import requests

    Obtener todas las quesadillas#

    response = requests.get("https://api.quesadilla.com/v1/quesadillas") quesadillas = response.json()

    Crear un nuevo pedido#

    order_data = { "type": "chicken", "size": "large", "extras": ["guacamole", "sour_cream"] } response = requests.post("https://api.quesadilla.com/v1/orders", json=order_data) ```

    ```javascript // Obtener todas las quesadillas fetch('https://api.quesadilla.com/v1/quesadillas') .then(response => response.json()) .then(data => console.log(data));

    // Crear un nuevo pedido const orderData = { type: 'chicken', size: 'large', extras: ['guacamole', 'sour_cream'] };

    fetch('https://api.quesadilla.com/v1/orders', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify(orderData) }); ```

    ```bash

    Obtener todas las quesadillas#

    curl -X GET "https://api.quesadilla.com/v1/quesadillas"

    Crear un nuevo pedido#

    curl -X POST "https://api.quesadilla.com/v1/orders" \ -H "Content-Type: application/json" \ -d '{"type":"chicken","size":"large","extras":["guacamole","sour_cream"]}' ```

    Autenticación Requerida

    La mayoría de endpoints requieren autenticación. Asegúrate de incluir tu clave API en el header de Authorization. Consulta nuestra guía de autenticación para más detalles.
